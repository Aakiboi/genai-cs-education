Token usage

Exact per-request usage parsed from Claude Code's local transcripts (tools/token_usage.py). Each request is labeled with the activity and phase logged in logs/sessions.jsonl.

How to read this. Every request re-sends the whole conversation. Most of that comes back as cheap cache reads, but it still counts toward plan limits. A long context therefore makes every later request expensive. /clear resets the context to the spec files, and /compact shrinks it to a summary. The "context size per request" chart shows this: it grows within a session and drops after a clear or compact.
