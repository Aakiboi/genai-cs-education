Prompt Heuristic 1
• Prompt incrementally by app feature
– Prompts describe too many app features =>
• Code might be difficult to understand
• Code might be difficult to test
– Example prompt (bad):
• Develop a 3-tier app…
18
Prompt Heuristic 1
• Prompt incrementally by app feature 
(cont.)
– Example prompts (good):
• Develop the first endpoint …
• Develop the second endpoint…
• …
• Develop client-side code…
• Add authentication…
• Check security…
• …
19
Prompt Heuristic 2
• Be specific
– Describe inputs to the desired code
– Describe proper outputs from the desired 
code
– Describe proper handling of boundary cases 
by the desired code
– Describe proper error handling by the 
desired code
• Parameter validation
• Exception handling
– Provide examples as necessary

Prompt Heuristic 3
• Prompt at a moderate level of detail
– Prompts too shallow =>
• AI will guess
• You’ll waste time composing many follow-up 
prompts
• AI might “drift” during long prompt sequences
– Prompts too deep =>
• You’ll waste time composing the prompt!
• AI might be overwhelmed
• You might lose learning opportunities
22
Prompt Heuristic 3
• Prompt at a moderate level of detail 
(cont.)
– Prompts at moderate level =>
• Gives the model enough structure to be useful
• Gives the model enough flexibility to adapt
– Guide the AI, but don’t overwhelm the AI

Prompt Heuristic 4
• Require testing
– Require AI to write test code
• Maybe before it writes the production code!!!
– (If possible) require AI to compile production 
and test code
– (If possible) require AI to run the test code 
against the production code
26
Prompt Heuristic 5
• Remember to prompt for debugging 
– Show error messages
– Require corrections
27
Prompt Heuristic 6
• Remember to prompt for explanations
– Ask the AI to explain any code that you don’t 
understand
28
Prompt Heuristic 7
• Record important decisions
– Command the AI to keep a record of 
important decisions in a history.md (or 
whatever) file
– Tell the AI to read the history.md file at the 
beginning of each conversation (or prompt)
